# ADR NNNN: <Tên quyết định ngắn gọn>

- **Ngày:** dd/mm/yyyy
- **Người quyết định:** <họ tên, hoặc "cả nhóm tại buổi họp dd/mm">
- **Trạng thái:** Đề xuất | Đã chấp nhận | Đã thay thế bởi ADR NNNN

## Bối cảnh

Vấn đề cần quyết định là gì? Ràng buộc nào (thời gian, yêu cầu của giảng viên, năng lực nhóm, bản chốt phạm vi)?

## Quyết định

Nhóm chọn gì. Viết ngắn, khẳng định, kiểm tra được.

## Phương án đã cân nhắc

| Phương án | Ưu điểm | Nhược điểm |
| --- | --- | --- |
| A (đã chọn) | | |
| B | | |

## Hệ quả

- Điều gì trở nên dễ hơn.
- Điều gì trở nên khó hơn, rủi ro nào cần theo dõi.
- Tài liệu, mã nguồn nào cần cập nhật theo.
